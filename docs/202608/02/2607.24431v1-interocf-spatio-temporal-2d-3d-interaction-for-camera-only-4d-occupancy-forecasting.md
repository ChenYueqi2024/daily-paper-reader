## 摘要
纯相机4D占用预测使自动驾驶车辆能够仅从历史多视角图像预测未来3D语义场景，这对驾驶安全至关重要。尽管当前方法已取得良好性能，但输入多视角帧之间的强时空建模仍未得到充分探索，这限制了这些方法在未来4D预测中的性能。为解决这一问题，我们提出了一种新颖的4D占用预测框架InterOCF，该框架同时建模基于3D体素表示和多视角分割序列中的时间动态，并明确引入2D与3D分支之间的特征交互。我们的框架包含三个核心组件：1) 3D时空(3DST)模块，从历史体素状态学习体积动态以预测未来体素状态；2) 2D时空(2DST)模块，采用辅助的多视角时间分割预测任务以增强时间语义动态；3) 时空交互建模(STIM)模块，实现2D和3D表示之间的特征交互。在nuScenes、Lyft-Level5和nuScenes-Occupancy数据集上的实验表明，InterOCF始终优于现有基线方法。

## Abstract
Camera-only 4D occupancy forecasting enables autonomous vehicles to predict future 3D semantic scenes solely from historical multi-view images, which is critical for driving safety. Even though current methods have achieved good performance, the strong spatial-temporal modeling between the input multi-view frames is still underexplored, which limits the performance of those methods in future 4D forecasting. To address this gap, we introduce a novel framework, InterOCF, for 4D occupancy forecasting that jointly models temporal dynamics in both 3D voxel-based representations and multi-view segmentation sequences, while explicitly incorporating feature interaction between the 2D and 3D branches. Our framework incorporates three core components: 1) A 3D Spatio-Temporal (3DST) module that learns volumetric dynamics from historical voxel states to predict future voxel states; 2) A 2D Spatio-Temporal (2DST) module employing an auxiliary multi-view temporal segmentation forecasting task to enhance temporal semantic dynamics; 3) A Spatio-Temporal Interaction Modeling (STIM) module that enables feature interaction between 2D and 3D representations. Experiments on the nuScenes, Lyft-Level5, and nuScenes-Occupancy datasets show that InterOCF consistently outperforms existing baseline approaches.

### 1. 核心问题与整体含义（研究动机和背景）

纯相机4D占用预测（Camera-Only 4D Occupancy Forecasting）是自动驾驶领域的关键任务，其目标是从历史多视角图像中预测未来3D语义场景，为智能驾驶提供前瞻性的环境感知能力。论文指出，现有的4D占用预测方法虽然取得了一定性能，但存在三大固有局限：

- **图像域信息利用不足**：多视角图像仅被一次性提升（lift）并融合到3D空间后即被弃用，丢失了高分辨率外观细节等丰富的视角专属信息。
- **纯3D时序外推效率低且不稳定**：直接在稀疏3D占用空间中进行时间维度上的推移（roll-out），长时预测极易受到误差累积的影响。
- **缺乏2D-3D交互建模**：现有方法未能显式建模2D多视角表示与3D占用动态之间的相互影响，限制了复杂驾驶场景下的时空推理能力。

针对上述问题，论文提出了**InterOCF**框架，通过联合2D与3D分支的时空建模并显式建立两者之间的特征交互，显著提升了4D占用预测的精度与鲁棒性。

### 2. 提出的方法论

#### 核心思想
InterOCF打破传统的"纯3D范式"，构建了一个**2D-3D交互式预测范式**：在2D多视角图像分割空间和3D体素占用空间两大表示中同时进行时空建模，并通过专门设计的交互机制实现信息双向流通。

#### 三大核心模块

**（1）3D时空模块（3DST）**
- 在**低分辨率体素空间**中使用ResNet3D编码器提取多尺度特征并进行时序建模，利用LSTM（Pre-LSTM）自回归地预测未来低分辨率体素状态，从而以较低的计算成本捕获全局运动模式。
- 引入**高分辨率上下文分支**（Context Branch），通过ResNet3D上下文编码器保留原始体素序列中的细粒度空间细节。
- 低分辨率预测结果与高分辨率上下文特征融合后，再经Post-LSTM增强时序一致性，最终上采样至原始分辨率输出。

**（2）2D时空模块（2DST）**
- 提出一个**辅助的多视角未来分割预测任务**，利用历史图像特征预测未来多视角语义分割序列，为3D几何推理补充丰富的语义线索和时间正则化约束。
- 设计了**Masked Inter-view Attention (MIA)** 机制，仅允许相邻视角相机之间进行信息交互，利用视角重叠区域提升跨视角特征一致性，同时控制计算开销。
- 语义分割标签由**Segment Anything Model (SAM)** 自动生成，无需人工标注。

**（3）时空交互建模模块（STIM）**
- STIM接收3DST模块的上下文特征与2DST模块的融合特征，通过**由粗到细的双层级联跨注意力机制**（Equation 8-10）实现双向特征交换。
- 先将低分辨率3D特征与2D特征跨注意力交互，逐步上采样并与高层级特征融合，最终生成精化后的上下文表示，实现2D外观细节与3D空间结构的互补融合。

#### 整体训练流程
- 先不启用STIM模块训练24个epoch，再引入STIM模块以较低学习率微调6个epoch。
- 损失函数由三部分组成：2D分割损失（交叉熵，权重0.05）、3D占用预测损失（交叉熵，权重0.5）和光流预测损失（Smooth L1，权重0.5）。
