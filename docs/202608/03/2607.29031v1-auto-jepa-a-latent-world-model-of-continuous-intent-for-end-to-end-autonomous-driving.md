## 摘要
现有的自动驾驶世界模型通常执行未来视频、占用状态、BEV表示或智能体运动的密集预测。我们认为，规划不必重建完整的未来世界，而只需关注影响未来自我（ego）动作的场景特征。基于这一视角，我们提出了Auto-JEPA，一种面向动作的潜在世界模型，通过联合嵌入预测学习连续的未来驾驶意图。给定视觉观测、自我运动历史与导航指令，Auto-JEPA预测与未来自我轨迹的潜在表示对齐的意图嵌入。预测的意图从固定轨迹记忆中检索可执行的轨迹，并由场景条件的候选选择模块排序。Auto-JEPA保持视觉编码器冻结，不需要显式的感知标注，且不使用学习的轨迹生成器。通过仅优化面向任务模块（轨迹表示、意图预测与候选选择），Auto-JEPA在NAVSIM v1上达到91.3 PDMS，在NAVSIM v2上达到89.1 EPDMS。语义遮挡实验表明，遮挡动态智能体区域引起的平均意图变化是等面积随机遮挡的2.97倍。此外，遮挡影响未来驾驶的车辆会显著改变预测意图与所选轨迹，而遮挡不影响的车辆则几乎不改变两者。这些结果表明，未来意图预测鼓励模型关注与规划相关的视觉特征，并支持无需密集未来世界建模的高质量规划。

## Abstract
Existing autonomous-driving world models typically perform dense prediction of future videos, occupancy states, BEV representations, or agent motion. We argue that planning need not reconstruct the complete future world, but only focus on scene features that affect future ego action. Based on this perspective, we propose Auto-JEPA, an action-oriented latent world model that learns continuous future driving intent through joint-embedding prediction. Given visual observations, egomotion history, and navigation commands, Auto-JEPA predicts an intent embedding aligned with the latent representation of the future ego trajectory. The predicted intent retrieves executable trajectories from a fixed trajectory memory, which are then ranked by a scene-conditioned candidate selection module. Auto-JEPA keeps the visual encoder frozen, requires no explicit perception annotations, and uses no learned trajectory generator. By optimizing only task-specific modules for trajectory representation, intent prediction, and candidate selection, Auto-JEPA achieves 91.3 PDMS on NAVSIM v1 and 89.1 EPDMS on NAVSIM v2. Semantic occlusion experiments show that masking dynamic-agent regions induces an average intent change 2.97x that of equal-area random masking. Moreover, occluding vehicles that affect future driving substantially changes the predicted intent and selected trajectory, whereas both remain essentially unchanged when non-influential vehicles are occluded. These results show that future-intent prediction encourages the model to focus on planning-relevant visual features and supports high-quality planning without dense future-world modeling.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：现有自动驾驶世界模型（driving world models）通常以**密集未来预测**为学习目标，例如预测未来多视角视频、占据场（occupancy）、BEV 表示或多智能体运动轨迹。论文认为，**规划并不需要重建完整的未来世界**，而只需关注“影响未来自我（ego）动作”的场景特征。
- **关键矛盾**：预测场景中所有可观测实体（无论其对自车即时决策是否有影响）会带来三方面弊端：
  1. 大幅增加计算开销；
  2. 将感知与预测的误差传播到下游规划；
  3. 模型容量被大量分配到与决策无关的场景元素上。
- **论文立场**：提出一种“规划导向（planning-oriented）”的预测范式——**以未来自车轨迹的潜在表示为预测目标**，而非重建全部未来场景。这一目标间接迫使模型筛选与规划相关的视觉信息。
- **整体含义**：Auto-JEPA 验证了“意图级潜在世界模型”这一路线的可行性：无需中间感知输出、无需密集未来重建、仅用单目前视相机，即可在 NAVSIM 两个版本上达到与复杂多传感器、VLA 方法相当甚至更优的规划性能。

## 2. 论文提出的方法论

### 2.1 核心思想

- 将规划问题转化为**连续驾驶意图的联合嵌入预测（joint-embedding prediction）**：从当前视觉观测、自车运动历史与导航指令中，预测一个与“未来自车轨迹潜在表示”对齐的意图嵌入。
- **预测目标**是未来自车轨迹的冻结编码器表示，而非未来图像/占据场等场景重建，因此模型被鼓励只保留对规划有判别力的信息。
- **推理链路**：预测意图 → 从固定轨迹记忆库检索 Top-K 候选轨迹 → 场景条件打分器排序 → 可行驶区域门控筛选 → 最终轨迹输出（非参数化，无学习式轨迹生成器）。

### 2.2 两阶段训练流程

**阶段一：轨迹潜在空间预训练（Trajectory Latent-Space Pretraining）**

- 未来自车轨迹表示为 8 个二维路点：Y = [(x₁,y₁),…,(x₈,y₈)] ∈ R^{8×2}（4 秒时域，0.5 秒间隔）。
- 用**轨迹自编码器**学习潜在空间：编码器 E_traj 将轨迹映射为 8 个潜在 token（Z⁺ ∈ R^{8×1024}），轻量解码器重建轨迹。
- 重建损失：L_traj = L_xy + λ_e·L_end + λ_v·L_vel + λ_a·L_acc（分别监督路点坐标、终点、速度、加速度）。
- 预训练后：**解码器丢弃，轨迹编码器冻结**，同时作为（a）意图预测的监督目标、（b）轨迹记忆库的索引编码器，确保预测与检索处于同一潜在空间。

**阶段二：视觉意图预测（Visual Intent Prediction）**

- 输入 X = (I, H, C)：
  - I：4 帧前视相机图像（256×256）；
  - H ∈ R^{4×2}：4 个历史自车位置；
  - C ∈ R⁴：导航指令。
- 编码：
  - 冻结的 V-JEPA 2 视觉编码器提取视觉 token；
  - 历史编码器、指令编码器映射到预测器特征维度。
- 预测器：24 层 Transformer（隐藏维 1024、16 头），融合视觉/历史/指令特征，输出 8 个未来潜在 token：Ẑ = P_θ(F_v, F_h, F_c) ∈ R^{8×1024}。
- 训练期间视觉编码器保持冻结，仅优化历史编码器、指令编码器与 JEPA 预测器。

### 2.3 联合嵌入训练目标

| 目标 | 形式 | 作用 |
|---|---|---|
| 特征对齐 L_feat | 预测与目标潜在归一化后的 Smooth L1 损失 | 整体特征值对齐 |
| Token 级余弦对齐 L_cos | 8 个时间位置对应 token 的余弦距离均值 | 保持时间与运动语义的对齐 |
| 批次级 InfoNCE L_NCE | 展平序列后，场景 i 的目标为正样本、其他场景为目标负样本，温度 τ=0.07 | 保持跨场景判别性，避免不同驾驶场景映射到相似表示 |

总目标：**L_intent = 0.1·L_feat + 2.0·L_cos + L_NCE**

### 2.4 推理流程（非参数化轨迹检索）

1. **轨迹记忆库**：仅由 NAVSIM 训练集中的真值轨迹构成（N = 110,335），每条轨迹用冻结的轨迹编码器编码为“潜在-路点”对。
2. **检索**：预测意图展平并 L2 归一化后，与记忆库做平坦余弦相似度排序，取 Top-K（K=300）。
3. **场景条件打分器（Scorer）**：从公开 CLOVER 轨迹打分器初始化，在 Auto-JEPA 的真值候选分布上重新优化；输入为场景特征、自车上下文与候选轨迹，监督信号包括碰撞、可行驶区域、TTC、舒适度、自车进展以及场景内排序损失。
4. **可行驶区域门控（DAC Gate）**：独立训练的二元分类器，预测候选轨迹发生 DAC 违规的概率，阈值 τ_DAC = 0.2；被判定为高风险（p > 0.2）的候选被屏蔽。
5. **最终选择**：在通过门控的候选中按打分器得分取 argmax；若全部被拒则回退到无门控排序。

## 3. 实验设计

### 3.1 数据集与基准

- **NAVSIM v1**：数据驱动的非反应式规划基准。指标包括无过错碰撞（NC）、可行驶区域合规（DAC）、碰撞时间（TTC）、舒适度（C）、自车进展（EP），聚合为 **PDMS**。测试集为完整 navtest（12,146 个场景）。
- **NAVSIM v2**：扩展评估集，额外包含行驶方向合规（DDC）、红绿灯合规（TL）、车道保持（LK）、历史舒适度（HC）、扩展舒适度（EC）等，聚合为 **EPDMS**。实验中启用了人类行为过滤与更新版官方实现。
- 打分器/门控训练数据：75,823 个训练场景 + 8,459 个验证场景，采用场景前缀划分（scene-prefix split），确保验证集与 navtest 在 metric token 上零重叠。

### 3.2 对比方法

- **端到端规划方法**：TransFuser、PARA-Drive、Hydra-MDP、DiffusionDrive、VADv2、HydraMDP++、DriveSuprim；

### 3.3 主要结果

- **NAVSIM v1**：Auto-JEPA 仅用单目前视相机达到 **91.3 PDMS**（NC 98.4、DAC 98.3、TTC 95.0、C 100.0、EP 87.1），超过表格中所有对比方法，包括多传感器方法（如 DiffusionDrive 88.1、Hydra-MDP 86.5）和 VLA 方法（如 Curious-VLA 90.3、DriveVLA-W0 90.2）。
- **NAVSIM v2**：原始评估实现下为 85.6 EPDMS，更新版官方实现下为 **89.1 EPDMS**（主要提升来自 TL 和 LK 指标），与 CLOVER（90.4，使用学习式生成器-打分器）接近但无需参数化轨迹生成。

## 6. 论文的主要结论与发现

1. **规划无需完整未来重建**：以未来自车轨迹潜在表示作为预测目标，足以支撑高质量端到端规划；模型将容量集中于规划相关特征而非全部场景内容。
2. **联合嵌入预测 + 非参数检索是可行的规划范式**：Auto-JEPA 用意图潜在作为检索键，从固定轨迹记忆中取回几何明确的候选，再经场景条件打分层筛选，形成完整的“传感器→轨迹”端到端接口，全程无中间感知输出、无学习式轨迹生成器。
3. **选择性地关注场景要素是涌现行为而非显式监督**：模型未接收任何目标框、智能体身份、交互标签或周围运动标注，却在遮挡实验中自然表现出对“影响未来驾驶的车辆”更强的响应（意图变化与轨迹偏移均显著更大），对“不影响驾驶的车辆”几乎不响应。
4. **性能达到 SOTA 水平**：NAVSIM v1 上 91.3 PDMS 超过所有对比方法；NAVSIM v2 上 89.1 EPDMS 与 CLOVER（90.4）接近，且无需参数化轨迹生成器，验证了轻量级意图世界模型的竞争力。

## 8. 缺点与局限性

- **计算开销并未被真正消除，而是被转移**：论文强调"避免密集未来重建"以降低计算负担，但其 24 层 Transformer 预测器（1024 维、16 头）在 256×256 分辨率、4 帧输入下，仍需对 V-JEPA 2 输出的视觉 token 做全局自注意力融合；论文**未报告具体推理延迟与 FLOPs**，因此"轻量"主张缺少直接量化证据。对于实时性要求极高的自动驾驶系统，这一开销是否可接受仍是悬而未决的问题。
- **对离线专家轨迹库的强依赖**：记忆库完全由 NAVSIM 训练集中的真值轨迹构成（约 11 万条）。这带来两个隐忧：
  1. **分布外场景（OOD）能力有限**——若测试场景的合理驾驶行为不在记忆库覆盖范围内，检索式方法会因候选缺失而失败，缺乏生成式方法的连续泛化能力；
  2. 轨迹库规模与剪枝策略（去重、覆盖度分析）论文未做深入讨论，Top-K=300 的检索上限在更大规模数据下是否仍然高效、是否需要近似最近邻索引，均未验证。
- **打分器的训练依赖成本较高**：场景条件打分器虽从 CLOVER 初始化，但其训练需要真值候选轨迹上的碰撞检测、可行驶区域计算、TTC 等多个安全指标的显式计算，这部分监督信号的工程复杂度并未体现在"端到端"的简洁叙事中；且打分器在 v2 的更新官方实现下是否需重新训练、其迁移性如何，论文未展开。
- **单目视觉输入的固有天花板**：模型仅使用前视单目相机，缺少环视、激光雷达或高清地图输入。NAVSIM v2 中与 CLOVER 的差距（89.1 vs 90.4）以及 TL、LK 等指标的相对弱势，部分可能源于感知模态的限制；论文将 v2 的残差主要归因于评估实现差异，但模态单一对复杂交互场景（如无保护左转、交叉口）的规划上限影响未被充分讨论。
- **评估的统计严谨性不足**：主结果与消融均基于单次确定性评估，无多次重复试验的标准差或显著性检验；v2 结果还受官方实现版本切换影响（85.6→89.1），这一较大的指标波动令人对评估口径的稳定性产生疑虑。此外，语义遮挡实验虽在设计上精细，但仅报告了平均变化与响应比例，未提供不同场景类别（如高速、市区、夜间）下的分层统计。
- **对"选择性"的解读存在一定模糊性**：遮挡实验中动态智能体遮挡引起更大的意图变化，被解释为"模型学会关注规划相关车辆"。但存在另一种可能——动态车辆区域恰好遮挡了更多低层视觉特征（如纹理、边缘密度较高），导致的响应差异可能部分来自感知统计特性而非语义规划相关性。等面积随机遮挡对照能在一定程度上缓解这一疑虑，但无法完全排除（例如，动态车辆区域与道路标线、路沿的视觉显著性天然不同）。

## 9. 改进方向与潜在扩展

- **引入多模态输入与场景图先验**：在保持意图预测范式不变的前提下，将单目相机扩展为环视相机，或融合低成本雷达/众包地图信息，可能进一步提升 v2 上的 TL、LK 等规则敏感指标，缩小与 CLOVER 的差距。
- **生成式与检索式混合的轨迹解码**：可在检索候选的基础上，增加一个轻量化的轨迹精调网络（refinement head）对 Top 候选做局部形变，以弥补记忆库覆盖不足的问题，同时保留非参数化的运动学安全保证。
- **记忆库的动态增长与在线更新机制**：探索基于距离的轨迹去重、密度自适应采样，以及在部署后利用安全通过的 executed trajectories 增量扩充记忆库，使系统具备持续学习能力。
- **预测不确定性的显式建模**：当前意图预测器输出单点估计。可借鉴概率世界模型思路，引入随机潜变量或 Ensemble 预测，输出意图分布的多样性，再映射为候选轨迹集的多样化（如多峰检索），以应对复杂交互中的多模态未来。
- **更强的可解释性模块**：可基于注意力权重的归因分析，输出"模型当前关注了哪些图像区域"的可视化热力图，与遮挡实验相互印证，形成从行为证据到机制证据的闭环。
- **在更大规模真实路测数据上验证**：NAVSIM 是离线数据集驱动基准，不涉及闭环控制与真实物理交互。未来可在 nuPlan 闭环环境或真实车辆平台上验证 Auto-JEPA 在实际规划管线中的稳定性、延迟与安全冗余设计。

## 10. 总体评价与思考

Auto-JEPA 的核心贡献在于提出并验证了一个反直觉但有力的命题：**自动驾驶规划未必需要重建世界，只需要预测与自身决策相关的未来意图**。这一命题将世界模型的研究重心从"感知完备性"拉回"任务充分性"，与人类驾驶"选择性注意"的行为模式相呼应。在方法论上，它以冻结轨迹编码器统一监督信号与检索索引，以非参数记忆库替代学习式轨迹生成器，以打分器+门控解耦场景质量评估与安全约束，形成了高度模块化、低标注依赖的系统架构——这种简洁性本身就是一种学术价值。

然而，该工作也留下值得深思的问题：检索式方法在当前以数据驱动 benchmark 为主的评估体系下表现出色，但其在开放世界长尾场景中的鲁棒性、在闭环真实车辆中的实时性、以及"意图预测是否真的学习了因果性的规划相关性"（而非仅统计相关性），仍需要更严格的验证。"意图级世界模型"这一路线若要成为自动驾驶的主流范式，还需在训练效率、记忆扩展性与闭环安全性上提供更有说服力的证据。总体而言，Auto-JEPA 是一个思想性突出、实验扎实、写作清晰的工作，为驾驶世界模型开辟了一条值得继续探索的轻量级路径。
