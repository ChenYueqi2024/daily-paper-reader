## 摘要
从视频序列预测未来状态是自主机器人系统面临的关键挑战，也是世界建模的基本目标。先前在像素级别操作的生成方法不可避免地过度强调与任务无关的细节，导致计算开销过高。虽然基于潜变量的方法试图通过直接预测特征来缓解这一问题，但状态到任务映射对重型解码器的持续依赖仍然是计算瓶颈。在本工作中，我们提出无解码器特征预测（DF$^3$），一种完全在潜空间内建模世界演化并直接推导任务输出的新颖框架，彻底消除了对解码器的需求。具体而言，DF$^3$ 将可学习的空间查询注入冻结视觉基础模型的末端块，直接提取未来状态表示。通过采用轻量级统一的运动感知上下文融合（MACF）机制，无缝集成粗粒度光流扭曲与细粒度潜变量互相关，这些查询与历史令牌表示交互，显式对齐并预测下一帧的特征。随后，一组专门的任务查询探测这些预测特征以用于下游任务。在公共基准和机器人模拟器零样本部署上的大量实验表明，DF$^3$ 在实现与最先进方法相当的性能的同时，为集成感知与控制提供了更高的效率和灵活性。

## Abstract
Forecasting future states from video sequences is a critical challenge for autonomous robotic systems and a fundamental objective of world modeling. Prior generative methods operating at the pixel level inevitably overemphasize task-irrelevant details, leading to prohibitive computational overhead. While latent-based approaches attempt to mitigate this by predicting features directly, the persistent reliance on heavy decoders for state-to-task mapping remains a computational bottleneck. In this work, we propose Decoder-Free Feature Forecasting (DF$^3$), a novel framework that models world evolution entirely within the latent space and directly derives task outputs, completely eliminating the need for a decoder. Specifically, DF$^3$ injects learnable spatial queries into the terminal blocks of a frozen vision foundation model to extract future state representations directly. By employing a lightweight, unified Motion-Aware Context Fusion (MACF) mechanism that seamlessly integrates coarse flow warping with fine-grained latent cross-correlation, these queries interact with historical token representations to explicitly align and forecast the feature of the next frame. Subsequently, a specialized set of task queries probes these forecasted features for the downstream task. Extensive experiments on public benchmarks and zero-shot deployment in a robotic simulator demonstrate that DF$^3$ achieves performance comparable to state-of-the-art methods while offering superior efficiency and flexibility for integrated perception and control.

## 1. 核心问题与整体含义（研究动机与背景）

本文聚焦于自动驾驶与机器人系统中**世界建模**（World Modeling）的关键问题——从视频序列预测未来状态。论文指出现有方法的根本矛盾在于：

- **像素级生成方法**（如视频生成模型）：直接在原始像素空间预测未来帧。此类方法存在三重缺陷：(1) 计算开销巨大；(2) 过度关注任务无关的细节（纹理、光照等高频信息）；(3) 预测结果必须经过额外感知解码器才能转化为任务输出，增加延迟。
- **潜空间预测方法**（如 DINO-WM、DINO-Foresight）：虽在语义特征空间预测，降低了计算负担，但仍依赖**重型解码器**——既需要解码器来完成上下文建模和特征重建，又需要额外的任务专用解码器将预测特征翻译为下游任务输出，形成新的计算瓶颈。

**核心研究问题**：能否完全在视觉基础模型（VFM）的编码器空间内完成特征预测，彻底摆脱解码器？

作者受到 EoMT（Encoder-only Mask Transformer）的启发——该工作证明冻结的普通 ViT 可通过任务查询注入完成密集预测任务而无须专用解码器。基于此，本文提出 **DF³（Decoder-Free Feature Forecasting）**，首次将无解码器范式引入复杂特征预测任务，完全在冻结的 ViT 编码器内部完成未来状态预测与下游任务推导。

## 2. 方法论

### 2.1 总体框架

给定历史上下文帧 {I₁, ..., I_T}，目标是在冻结的 DINOv3-ViT-B/16 编码器 E 的潜空间内预测下一帧特征 F̂_{L1}(I_{T+1})。整体流程如下：

1. 每帧经 patch embedding 和位置编码后输入 ViT
2. 取编码器**早期层 L1 的输出**作为上下文特征（包含 prefix tokens 和 patch tokens）
3. 将**可学习预测查询 Q_pred** 注入编码器**末端块 L2**，与历史特征拼接后经过自注意力交互
4. 预测查询输出经 MACF 机制精炼，得到预测的未来特征
5. 下游任务时，将**任务查询 Q_task** 同样注入 L2，与预测特征交互后经轻量 MLP 头产生分割等任务输出

### 2.2 关键技术细节

**（1）结构化查询注意力（Structured Query Attention）**

在末端块的自注意力层中引入**非对称注意力掩码** M∈{0,1}^(Nq+Nc)×(Nq+Nc)：

- 预测查询 (i < Nq)：可关注所有 token（历史上下文 + 其他查询）
- 上下文 token (i ≥ Nq)：只能关注上下文 token，**被禁止回看预测查询**

这一因果掩码设计防止信息泄漏，确保注入的查询不会污染上下文表征。

**（2）运动感知上下文融合（MACF, Motion-Aware Context Fusion）**

MACF 是解决"冻结图像编码器缺乏时间建模能力"这一核心挑战的关键，包含两个并行分支：

- **Flow-based Warp 分支（粗粒度）**：从空间预测查询中预测稠密潜空间光流场 Δp = MLP_flow(q_patch)，用光流将最近历史特征图 f_{L1}(I_T) 扭曲到未来时刻，得到粗对齐特征 f̃_warp，并计算其与当前查询的差异作为更新方向 M_warp。
- **Latent Cross-Correlation 分支（细粒度）**：在局部窗口 (2r+1)×(2r+1) 内对 f_{L1}(I_{T-1}) 与 f_{L1}(I_T) 做软匹配（soft-matching），得到历史语义运动 V_hist，再投影为语义运动注入 M_xcorr。

**动态融合**：两分支输出经拼接后由 MLP 融合，经**可学习的 sigmoid 门控机制** G(q_patch) 调节残差权重：

F̂_{L1}(I_{T+1}) = q_patch + G(q_patch) ⊙ MLP_fuse([M_warp, M_xcorr])

**（3）训练目标**

采用特征级监督，结合余弦相似度（对齐方向）与 Huber 损失（稳定幅度）：

L_sim = E_t[1 − cos(F̂_{L1}(I_{t+1}), F_{L1}(I_{t+1})) + λ_huber · Huber(...)]

对 patch tokens 和 prefix tokens 均计算损失。

## 6. 主要结论与发现

1. **性能上**：DF³ 短期预测达到 69.9 mIoU / 68.7 MO-mIoU，中期 58.2 / 56.5。相比 DINO-Foresight（71.8 / 71.7）略有下降，但差距很小（约 2 个点）。
2. **效率上**：DF³ 大幅降低计算成本——FLOPs 减少 **36%**，推理延迟降低 **70%**（971ms → 292ms），峰值 GPU 内存减少 **67%**（9.5GB → 3.1GB），参数量减少 **41%**。
3. **消融结论**：Warp 与 Xcorr 两分支互补——warp 处理粗粒度位移和遮挡，xcorr 细化局部对齐和快速运动；两者结合效果最佳（69.9 vs 单独 63.6/65.7）。
4. **搜索半径**：r={1,2,4,8} 最优，过大（含 16）会稀释相关信号、增加噪声敏感度。
5. **零样本迁移**：仅在 Cityscapes 汽车视角训练后，可直接部署到四足机器人模拟器，规划轨迹与 Oracle 轨迹保持良好空间对齐，验证了潜空间表征的跨具身泛化能力。

## 7. 优点

- **范式创新**：首次实现完全在冻结 ViT 编码器内完成未来特征预测与任务输出，彻底消除解码器这一计算瓶颈，概念上具有开创性
- **冻结骨干 + 轻量模块**：不微调预训练权重，仅训练查询向量和轻量 MLP 融合模块，训练成本低且保留基础模型的语义能力
- **MACF 设计精巧**：将光流扭曲与互相关融合并通过门控机制动态调节，以极轻量方式为静态编码器注入时间建模能力，是解决"冻结编码器缺乏时间感知"的有效方案
- **灵活解耦**：预测查询与任务查询可独立训练和使用，利于模块复用与扩展
- **零样本部署验证**：跨视角、跨具身（汽车→四足机器人）的部署实验有力证明了表征的泛化性和实用性

## 8. 不足与局限

- **性能权衡**：相比 DINO-Foresight 有约 2 个 mIoU 的精度差距，且论文明确承认**空间过平滑**问题——物体边界粗糙、细长结构模糊，这是冻结下采样特征空间的固有代价
- **缺少动作条件**：目前仅支持观测式未来预测，不支持动作条件预测（action-conditional），无法用于闭环控制和交互环境中的规划——作者在 Limitation 部分也明确承认
- **实验覆盖有限**：仅单一数据集（Cityscapes）、单一基线（DINO-Foresight）；缺乏在多样化动态场景（恶劣天气、夜间）和多类别物体上的评估
- **公平性考量**：DF³ 使用 DINOv3-ViT-B/16 骨干，DINO-Foresight 使用的骨干未在文中明确，严格公平对比存在不确定性
- **模拟器部署的视觉质量**：四足机器人场景中预测特征明显更粗糙、存在空间错位，作者将其归因于领域差异，但未报告该场景下的定量性能指标
- **计算细节遗漏**：未报告端到端任务查询+预测查询联合推理的完整延迟、训练总时长、单卡等效训练时间等
