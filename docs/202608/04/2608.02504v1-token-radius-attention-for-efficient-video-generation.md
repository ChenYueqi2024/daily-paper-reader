## 摘要
视频扩散变换器（VDiT）能够实现高保真生成，但密集的3D自注意力带来了二次方成本。现有的头级和块级稀疏方法在查询之间共享计算预算，忽略了令牌特定的注意力需求。我们观察到，保留密度因查询而异，但与注意力熵呈对数线性相关，而主导交互形成以查询为中心的邻域，其半径取决于令牌。基于这些发现，我们提出了令牌半径注意力（TRA），一种无需训练框架，将查询熵映射到解析令牌预算，并将其转换为时间衰减的半径，无需显式键排序。融合熵提取、预热复用和块稀疏掩码构建进一步减少了开销。在Wan2.1、Wan2.2和HunyuanVideo T2V/I2V的七种配置中，TRA仅保留9%-19%的注意力交互，实现了1.56倍至2.05倍的加速，且生成质量具有竞争力。代码可在 https://github.com/IF-LAB-PKU/Token-Radius-Attention 获取。

## Abstract
Video Diffusion Transformers (VDiTs) enable high-fidelity generation but incur quadratic cost from dense 3D self-attention. Existing head- and block-level sparse methods share computation budgets across queries, overlooking token-specific attention demand. We observe that retained density varies across queries yet correlates log-linearly with attention entropy, while dominant interactions form query-centered neighborhoods with token-dependent radii. Based on these findings, we propose Token Radius Attention (TRA), a training-free framework that maps query entropy to an analytic token budget and converts it into a temporally decayed radius without explicit key ranking. Fused entropy extraction, warm-up reuse, and block-sparse mask construction further reduce overhead. Across seven Wan2.1, Wan2.2, and HunyuanVideo T2V/I2V configurations, TRA retains only 9-19% of attention interactions and achieves 1.56x-2.05x speedup with competitive generation quality. Code is available at https://github.com/IF-LAB-PKU/Token-Radius-Attention.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：视频扩散Transformer（VDiT）已成为高保真视频生成的代表性架构（如 Wan、HunyuanVideo），但其依赖密集 3D 自注意力来建模时空依赖，计算复杂度为 O(N²)（N 为视频令牌数）。随着视频时长和分辨率的提升，注意力计算成为推理性能的严重瓶颈。
- **现有方法局限**：
  - 头级（head-level）方法（如 SVG、Radial Attention、Sparse-vDiT）为每个注意力头分配固定空间/时间模式；
  - 块级（block-level）方法（如 SVG2、SpargeAttn、SVOO）选择重要的查询-键块对；
  - 两种范式都**在头或块内共享单一计算预算**，隐含假设同组查询的注意力需求相同。这不符合自注意力的逐行归一化本质——软最大值独立作用于每个查询，不同查询的注意力分布集中/分散程度差异巨大，共享预算会导致集中型查询计算浪费、分散型查询丢失关键键。
- **核心问题**：如何在查询令牌粒度实现自适应稀疏分配，同时保持可执行的结构化稀疏模式，兼顾"自适应性"与"高效性"的平衡。
- **整体思路**：TRA 利用两项实证发现——（1）保留密度与注意力熵近似对数线性相关；（2）主导注意力交互呈查询中心圆邻域分布，从而将"查询熵 → 令牌预算 → 时空半径"的流水线实现无需训练的令牌级稀疏注意力，在不进行显式键排序的前提下将预算转化为规则的结构化掩码。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 两大经验洞察

- **洞察 I：令牌特异稀疏性**：保留密度 Bτi = Kτi/N（为达到目标注意力质量 τ 所需的最少 top 键比例）在不同查询间跨越数量级变化，且 log Bτi 与注意力熵 Hi 近似线性相关（R² = 0.940–0.966）。熵因此可作为查询特异预算的紧凑信号，无需训练预测器或逐查询键排序。
- **洞察 II：令牌半径注意力模式**：高注意力键形成以查询为中心的近似圆形空间邻域，且归一化注意力概率随二维空间距离近似指数衰减（R² = 0.791–0.994）。半径可将标量预算转化为单调、规则的结构化空间支撑。

### 2.2 熵到预算映射（Entropy-to-Budget Mapping）

- **有效支持近似**：定义熵等效均匀分布 p′ᵢⱼ = 1/mᵢ（|Sᵢ| = mᵢ），令其熵等于原始注意力熵 Hi，得 mᵢ = exp(Hi)，即熵等效有效支持大小。
- **解析预算公式**：在上述近似下，估计达到目标注意力质量 τ 所需键数为：
  - K̂τᵢ = ⌈τ·exp(Hi)⌉
  - 有效令牌预算：B̂τᵢ = K̂τᵢ/N ≈ τ·exp(Hi)/N
- 该映射为解析、单调、无参数的，低熵查询分配小预算，高熵查询分配大预算。

### 2.3 预算到半径掩码构建（Budget-to-Radius Mask Construction）

- **时间衰减模型**：采用指数时间距离衰减 ϕ(δ) = exp(−γδ)，帧 t 的半径为 rᵢ,ₜ = rᵢϕ(|t − fᵢ|)。γ 全局共享，查询自适应仅通过基础半径 rᵢ 体现。
- **预算匹配半径构造**：
  - 连续近似：C_contᵢ(r) = Σₜ πr²ϕ²(|t−fᵢ|)，令其等于 K̂τᵢ 得到解析初值 r̃ᵢ；
  - 网格精确计数：对候选半径计算离散保留键数 C_gridᵢ(r)，取满足 C_gridᵢ(r) ≥ K̂τᵢ 的最小半径作为最终 rᵢ（边界感知）。
- **掩码定义**：Mᵢⱼ = I[dₛ(i,j) ≤ rᵢϕ(|fⱼ−fᵢ|)]，查询特异但结构规则。文本键保持全可见。

### 2.4 高效实现（Efficient Radius Masking and Entropy）

- **Flash Radius Mask 内核**：
  - 将每帧按 H×W 划分为空间瓦片并采用瓦片主序重新排列令牌，使邻近令牌在一维序列中连续，降低块稀疏化开销；
  - 融合距离计算、半径比较、块剪枝与令牌投票于单个 CUDA 内核：先以空间包围盒拒绝不可能的块对，再逐令牌评估剩余候选，按覆盖率阈值决定块是否保留；
  - 二维序列距离消融使用 ρ₁D = (π/2)ρ²₂D 进行面积匹配。
- **融合注意力熵内核**：利用熵的在线软最大值恒等式 Hi = log Zi − Σⱼ pᵢⱼsᵢⱼ，在不物化完整注意力矩阵的情况下与稠密注意力前向同步累积熵。
- **跨步骤复用**：在去噪过程前 25% 的稠密预热步计算熵，后续稀疏步骤直接复用预算、半径和掩码，消除重复开销。
- **整体流水线**：熵提取 → 预算解析 → 半径查表 → 时空掩码 → 瓦片重排 → 块稀疏掩码 → FlashInfer 执行。

## 6. 主要结论与发现

1. **令牌级稀疏性显著存在**：视频自注意力中保留密度在不同查询间差异巨大，且与注意力熵呈对数线性相关，共享预算假设不成立。
2. **注意力呈查询中心半径模式**：高权重键分布在以查询为中心的圆邻域内，注意力概率随空间距离指数衰减，支持半径作为结构化支撑参数。
3. **TRA 实现高质量-效率平衡**：
   - 在全部 7 个配置中获得稀疏方法中最佳 VBench Overall 分数；
   - 仅保留 9%–19% 的注意力交互；
   - 实现 1.56×–2.05× 端到端加速（HunyuanVideo 上最高 2.05×）；
   - 在 Wan2.1-14B T2V 上几乎匹配稠密注意力质量。
4. **内核设计有效性**：Flash Radius Mask 和 Fused Attention Entropy 分别实现 10.35× 和 12.34× 相对朴素实现的加速，使决策开销可忽略。
5. **免训练即插即用**：TRA 无需训练或修改权重，可直接应用于现有开源模型。

## 8. 不足与局限

### 8.1 论文自述局限

- **受限且静态的稀疏模式**：基于距离先验的模式可能无法捕获内容依赖的交互（如长距离物体对应、非局部运动、场景判别性注意力结构）。未来需探索在线令牌选择或更丰富的自适应模式。
- **缺乏专用令牌级稀疏核**：TRA 依赖现有块稀疏后端，瓦片重排和块掩码虽降低分块开销但保留块内冗余计算。专用融合内核可进一步提升实际效率。

### 8.2 实验与评估层面的局限

- **基线公平性存疑**：Radial Attention 使用不同分辨率与帧数，对比条件不完全对等；
- **未进行人工评估**：VBench 自动评分无法完全反映主观视觉质量，视频生成领域通常需要人工偏好实验佐证；
- **缺乏统计显著性报告**：未提供多次运行的方差或置信区间；
- **超参通用性验证不足**：γ、τ、块大小等超参数仅在部分配置上测试，跨架构泛化证据有限；
- **效率评估硬件单一**：仅报告 H200 结果，未验证在 A100、消费级 GPU 上的加速效果。

### 8.3 应用限制

- 时间衰减因子（γ）需按模型手动设定（Wan 为 0.6，Hunyuan 为 0.95），削弱了完全即插即用的属性；
- 文本-视频联合注意力的处理方式随架构而异，对架构灵活性有一定要求；
- 高分辨率/长视频场景下的扩展性（token 数远超当前 129 帧）尚未充分验证。
