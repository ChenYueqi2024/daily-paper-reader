## 摘要
检测Transformer模型，包括DETR及其扩展，学习输出一组对象级嵌入，这些嵌入可以同时解码为2D边界框和类别分布。在本文中，我们研究了预训练的2D检测Transformer对物体3D属性的理解程度。具体而言，我们使用线性和非线性探针，探究从对象级嵌入中恢复物体相对相机的深度以及相对相机的3D位置等属性的程度。在一系列检测Transformer模型中，我们的结果显示出2D DETR模型在表示物体3D属性的有用信息方面具有惊人的强大能力，且这种能力先前未知，尽管模型在预训练期间完全缺乏3D监督。

## Abstract
Detection transformer models, including DETR and its extensions, learn to output a set of object-level embeddings that can be simultaneously decoded into 2D bounding boxes and class distributions. In this paper, we investigate what pre-trained 2D detection transformers understand about the 3D properties of objects. Specifically, we investigate the extent to which properties including the depth of objects from the camera and the 3D location of objects relative to the camera can be recovered from object-level embeddings using linear and non-linear probes. Across a range of detection transformer models, our results show a surprisingly strong and previously unknown ability of 2D DETR models to represent useful information about the 3D properties of objects, despite the complete lack of 3D supervision during model pre-training.

- **研究动机**：DETR 及其变体是仅使用 2D 边界框和类别标签（如 COCO）训练的检测 Transformer，其内部对象级嵌入（query embeddings）被认为只服务于 2D 检测任务。本文想探究一个此前未被回答的问题：这些 2D 检测器在完全没有 3D 监督的情况下，其对象嵌入中是否已经隐式编码了 3D 属性（如物体深度、相对相机的 3D 位置）。

## 2. 论文提出的方法论

- **核心思想**：采用“探针”（probing）方法，在冻结预训练检测器权重的前提下，训练一个简单的回归模型，从对象嵌入中预测 3D 属性；预测误差越低，说明嵌入中包含的 3D 信息越丰富。
- **探针类型**：
  - 线性探针：单层仿射映射，用于评估信息是否可线性解码。
  - 非线性探针：两层 MLP（ReLU 激活，隐藏维度 256），用于评估非线性可解码性。
- **任务定义**：
  - 单目深度估计：从对象嵌入预测物体边界框中心处到相机的深度值 \(d\)。
  - 3D 位置预测：从对象嵌入预测物体 3D 边界框中心在相机坐标系下的坐标 \((x, y, z)\)。
- **数据集构建流程**：
  1. 对每张输入图像运行预训练 2D DETR，得到对象嵌入、类别分布和 2D 框。

## 6. 论文的主要结论与发现

- **主要发现**：
  1. 2D DETR 模型的对象嵌入中编码了显著的 3D 属性信息，即使预训练时没有任何 3D 监督。
  2. 在深度估计任务上，使用 MLP 探针的 DETR 嵌入在 Virtual KITTI 2 上的 MAE 为 0.54m，优于零样本 Depth Anything 2（1.49m）；在 NYUv2 上也与零样本 Depth Anything 2 相当或更好（0.51m vs 0.61m）。
  3. 在 3D 位置预测任务上，最佳 DETR（原始 DETR）的 3D 中心 MAE 为 0.50m，仅比 MonoDETR（0.30m）差 0.2m；相对误差差距约 1%，而测试对象的中位距离为 25.3m，表明差距很小。
  4. 实时/轻量级变体（RT-DETR v2、LW-DETR）的 3D 表示能力明显弱于标准变体，推测与其减少模型层数和容量有关。
  5. 非线性探针显著优于线性探针，说明 3D 信息在嵌入中呈现非线性编码。
  6. PCA 压缩实验表明，深度相关信息集中在一个相对低维的子空间中；实时变体需要更多维度才能达到相同性能。
  7. 嵌入探针远优于 2D 框探针，证明嵌入中除了 2D 信息外还包含额外的语义/场景线索，有助于深度推理。

## 7. 优点

- **方法清晰**：采用成熟的探针框架，并针对目标检测模型设计了基于预测框和对象性过滤的数据集构建流程，逻辑严谨。
- **对比合理**：引入 Depth Anything 2 和 MonoDETR 作为强 3D 监督基线，并考虑了零样本、微调头等不同设置，增强了结论的可靠性。
- **分析细致**：包含类别级误差、层间差异、PCA 压缩、输入表示消融等，有助于理解 3D 信息的分布和编码结构。
- **结果具有启发性**：揭示了 2D 检测预训练隐式学习 3D 几何能力的现象，对未来 3D DETR 架构设计有潜在指导意义。
