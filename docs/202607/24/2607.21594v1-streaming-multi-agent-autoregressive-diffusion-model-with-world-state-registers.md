## 摘要
多智能体交互世界模型不仅应生成一致的观测，还需维护跨智能体持久且随视角演变的世界状态。现有的自回归视频扩散模型将观测历史作为条件上下文传递，这使得在多智能体、多视角设定下难以维护共享状态。我们提出WorldWeaver（W^2），一种流式多智能体视频扩散模型，通过跨智能体世界状态寄存器增强推理：这些可学习令牌存储共享世界信息、跟踪个体智能体状态，并在每个生成块后动态更新。我们利用覆盖个体智能体状态、全局状态视图（包括鸟瞰图）以及场景文本的监督信号来支撑这些寄存器。我们进一步采用混合Transformer架构改进模型，该设计对世界状态建模与视觉帧建模使用独立权重。在两个智能体的Minecraft视频生成任务中进行的广泛实验表明，显式世界状态建模提升了逻辑一致性与生成质量。

## Abstract
Multi-agent interactive world models should not only generate consistent observations, but also maintain world states that persist across agents and evolve across views. Existing autoregressive video diffusion pipelines carry forward observation history as conditioning context, which makes shared state difficult to maintain in multi-agent and multi-view settings. We present WorldWeaver (W^2), a streaming multi-agent video diffusion model that augments rollout with cross-agent world state registers: learnable tokens that store shared world information, track individual agent status, and are dynamically updated after each generated chunk. We ground these registers with supervision signals spanning individual agent status, global state views including bird's-eye views, and scene text. We further improve the architecture with a Mixture-of-Transformers design that uses separate weights for world state modeling and visual frame modeling. Extensive experiments in two-agent Minecraft video generation show that explicit world-state modeling improves logical consistency and generation quality.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **研究动机**：多智能体（multi-agent）交互世界模型不仅需要生成一致的视觉观测，还需要维护一个跨智能体、随视角演变的共享“世界状态”。现有的自回归视频扩散模型（如Diffusion Forcing、Solaris）仅将观测历史作为条件上下文传递，在单智能体场景中尚可工作，但在多智能体多视角场景下，每个智能体只能看到同一3D世界的部分2D投影，模型难以从局部帧历史中推断并维持一致的全局世界状态。此外，世界状态在无人观测时仍会变化，导致跨智能体逻辑一致性和几何一致性难以保证。
- **核心问题**：如何显式建模并在流式视频生成中维护动态可更新的共享世界状态，以提升多智能体视频生成的逻辑一致性和视觉质量。
- **整体含义**：提出一种新的范式——在生成过程中直接维护“世界状态寄存器”（World State Registers），而非让模型反复从帧历史中隐式推断世界状态。这为多智能体交互世界模型提供了更稳健、可验证的状态表示。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
### 2.1 核心思想
- **世界状态寄存器（World State Registers, WSR）**：一组可学习的令牌（tokens），用于存储共享的世界信息，并随生成步动态更新。寄存器具有两个关键属性：
  1. **持久性**：跨智能体、跨生成步保持共享。
  2. **动态可更新**：每当新观测到来时更新，所有智能体的观测共同贡献于状态更新。
- **三阶段训练课程**：在标准单智能体预训练基础上，分阶段训练多智能体模型：
  - **Stage 1（双向训练）**：使用全因果注意力训练多智能体双向教师模型，学习同步多智能体场景结构。
  - **Stage 2（因果训练+WSR监督）**：将教师转换为因果学生，采用因果注意力和滑动窗口，并插入WSR令牌。同时用辅助预测头对WSR进行监督：智能体状态（位置、速度、朝向）、鸟瞰图（BEV）特征、场景文本描述。
  - **Stage 3（自强制训练）**：模拟推理时的自回归生成，让学生模型暴露在自己生成的帧和已提交的寄存器上，使用DMD风格分布匹配损失对抗训练，并保留WSR监督。
- **Mixture-of-Transformers（MoT）架构**：为世界状态令牌和视觉帧令牌分配独立的权重参数（状态分支和视觉分支），但共享联合注意力机制。这避免了状态建模和帧生成的目标冲突，尤其在寄存器承载丰富语义时优势明显。

### 2.2 关键技术细节
- **WSR更新机制**：在因果序列中，寄存器 \( r_i \) 在帧 \( x_i \) 生成后提交，并作为条件用于下一帧 \( x_{i+1} \) 的生成。寄存器查询的注意力范围包括最近的W个上下文帧和前一寄存器。
- **监督信号**：
