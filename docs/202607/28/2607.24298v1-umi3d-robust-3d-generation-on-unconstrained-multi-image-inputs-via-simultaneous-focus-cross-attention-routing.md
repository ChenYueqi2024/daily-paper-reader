## 摘要
近期的基础三维模型可以从单张图像生成高质量资产，但在无约束多图像输入上性能显著下降，通常产生扭曲的几何形状、过度平滑的纹理和混乱的颜色。我们认为这种失败并非源于模型容量有限，而是由于单图像交叉注意力与多图像设置之间的不匹配：现有模型缺乏一种原则性方法来决定每个去噪步骤中每个三维体素应该信任哪张图像。重新审视近期的单图像基础三维模型，我们表明，将每个体素显式路由到其信息量最大的图像足以在不一致的多图像输入上实现强大的性能。基于这一观察，我们提出了UMI3D，一个无需训练、即插即用的框架，重构了无约束多图像三维生成的交叉注意力。其核心是同步聚焦交叉注意力（SFC-Attn），在每个去噪步骤中激活所有条件图像，同时允许每个体素聚焦于最能解释它的单张图像。为了实现这种路由，我们推导了体素参考分数（VRS），一种体素-图像亲和度的模型内在度量，无需外部匹配、分割或对应模型。大量实验表明，UMI3D在各种任务中释放了单图像三维生成框架的多图像潜力。项目页面：UMI3D-Project.github.io.

## Abstract
Recent 3D foundation models can generate high-quality assets from a single image, but degrade markedly on unconstrained multi-image inputs, often producing distorted geometry, over-smoothed textures, and chaotic colors. We argue that this failure stems not from limited model capacity, but from a mismatch between single-image cross-attention and the multi-image setting: existing models lack a principled way to decide which image each 3D voxel should trust at each denoising step. Revisiting recent single-image 3D foundation models, we show that explicitly routing each voxel to its most informative image is sufficient to unlock strong performance on inconsistent multi-image inputs. Based on this observation, we propose UMI3D, a training-free and plug-and-play framework that restructures cross-attention for unconstrained multi-image 3D generation. Its core, Simultaneous Focus Cross-Attention (SFC-Attn), activates all conditioning images at each denoising step while allowing each voxel to focus on the single image that best explains it. To enable this routing, we derive the Voxel Reference Score (VRS), a model-intrinsic metric for voxel--image affinity that requires no external matching, segmentation, or correspondence models. Extensive experiments show that UMI3D unlocks the multi-image potential of single-image 3D generation frameworks across diverse tasks. Project Page: UMI3D-Project.github.io.

## 1. 核心问题与研究动机

- **背景**：当前基于单张图像（single-image）的 3D 基础模型（如 Zero-1-to-3、SyncDreamer、InstantMesh 等）已能生成高质量 3D 资产，但将这些模型直接应用于**无约束多图像输入**（如随意拍摄的多视角照片，可能存在光照、背景、视角不一致甚至遮挡）时，性能急剧下降。典型问题包括几何扭曲、纹理过度平滑、颜色混乱等。
- **核心问题**：作者认为这种退化并非模型容量不足，而是**单图像交叉注意力机制与多图像设置不匹配**——现有模型缺乏一种原则性方法，来确定每个去噪步骤中每个 3D 体素应该信任哪一张图像。
- **研究动机**：揭示了一个惊人发现：只要将每个体素显式地路由到其信息量最大的图像（而不是简单平均或拼接所有图像特征），就足以在不一致的多图像输入上获得强性能。因此，设计一个无需训练、即插即用的框架来重构交叉注意力，释放单图像 3D 模型的多图像潜力。

## 2. 方法论：核心思想与关键技术

### 2.1 核心思想
- **同步聚焦交叉注意力（SFC-Attn）**：在每个去噪步骤中，**同时激活所有条件图像**，但允许每个体素**自动聚焦**到最能解释它的单张图像上，即体素仅从最相关的图像中获取信息，而非无差别地融合多图特征。
- **关键路由机制**：需要一种度量来判断体素与图像之间的亲和度（affinity），从而决定体素应该“看”哪张图。作者提出了**体素参考分数（Voxel Reference Score, VRS）**，这是一种**模型内在度量**，无需任何外部匹配、分割或对应模型。

### 2.2 技术细节
- **SFC-Attn 实现**：  
  - 输入：3D 体素特征（通常来自去噪 U-Net 的瓶颈层）和多张条件图像特征（由 CLIP 或 DINO 等编码器提取）。  
  - 对每个体素，计算它与每张条件图像的 VRS。  
  - 选择 VRS 最高的图像作为该体素的“参考图像”，然后仅对该图像做交叉注意力（而非对所有图做注意力融合）。  
  - 所有体素并行进行此操作。
- **体素参考分数（VRS）推导**：  
  - VRS 利用模型自身交叉注意力层中的查询（query）和键（key）的内积来度量体素与图像块的相似性。  
  - 具体地，对于体素 \(v\) 和图像 \(I_k\)，VRS 定义为该体素查询向量与图像 \(I_k\) 所有空间位置键向量的最大相似度（或平均相似度，论文中采用最大池化）。  
  - 无需训练：VRS 直接从模型当前去噪步骤的注意力分数中提取，因此是零成本。
- **算法流程（文字说明）**：  
  1. 输入多张无约束图像（任意数量、任意视角）。  
  2. 使用单图像 3D 基础模型（如 InstantMesh）的预训练权重，不对其进行任何微调。  
  3. 在每个去噪步骤中，将 3D 体素特征映射为查询，将每张条件图像的特征映射为键和值。  
  4. 计算每个体素对每张图像的 VRS。  
  5. 对每个体素，仅选择 VRS 最高的图像执行交叉注意力（即使用该图像的键和值）。  
  6. 其余步骤（如自注意力、U-Net 前向传播）保持不变。  
  7. 最终输出 3D 表示（NeRF 或 3D 网格）。

### 2.3 无需训练与即插即用
- 整个 SFC-Attn 模块无需任何额外训练或参数调整，可**直接替换**现有单图像 3D 基础模型中的交叉注意力层。
