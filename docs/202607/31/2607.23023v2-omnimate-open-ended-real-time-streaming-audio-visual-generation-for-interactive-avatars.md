## 摘要
近年来，基于扩散的生成模型取得了进展，使得实时音频驱动的虚拟形象生成和统一音视频合成成为可能，为交互式虚拟形象系统提供了有前景的基础。然而，将统一音视频合成扩展到实时交互式流式处理仍然具有挑战性，因为生成范围事先未知，且生成的身份可能在长期生成过程中发生漂移。为应对这些挑战，我们提出了OmniMate，一个用于开端式实时交互式音视频虚拟形象生成的统一框架。OmniMate实时联合合成视觉内容、语音和音效，实现自然且沉浸式的多轮交互。为实现自适应响应推进，我们引入了生成进度控制器（GPC），它显式建模每个流式块的生成进度，使模型能够根据期望的进度完成响应，并在执行和聆听状态之间实现无缝转换。为保持长期跨模态身份一致性，我们提出了多参考条件模块（MRCM），它利用多个参考图像和一个参考语音片段，在长时间流式交互中提供持久的视觉和说话人身份线索。在面向交互式适配的VerseBench上进行的广泛实验表明，OmniMate实现了高质量、低延迟的流式生成，同时保持了强大的长期音视频一致性。结果进一步表明，OmniMate在扩展的多轮对话中支持逼真、连贯且响应迅速的交互式虚拟形象体验。

## Abstract
Recent advances in diffusion-based generative models have enabled real-time audio-driven avatar generation and unified audio-visual synthesis, providing a promising foundation for interactive avatar systems. However, extending unified audio-visual synthesis to real-time interactive streaming remains challenging, as the generation horizon is unknown in advance and the generated identity may drift over long-term generation. To address these challenges, we propose OmniMate, a unified framework for open-ended real-time interactive audio-visual avatar generation. OmniMate jointly synthesizes visual content, speech, and sound effects in real time, enabling natural and immersive multi-turn interactions. To achieve adaptive response progression, we introduce a Generation Progress Controller (GPC) that explicitly models the generation progress of each streaming chunk, allowing the model to complete responses according to the desired progress and achieve seamless transitions between execution and listening states. To preserve long-term cross-modal identity consistency, we propose a Multi-Reference Conditioning Module (MRCM), which leverages multiple reference images and a reference speech segment to provide persistent visual and speaker identity cues throughout long-duration streaming interactions. Extensive experiments on an interaction-oriented adaptation of VerseBench demonstrate that OmniMate achieves high-quality, low-latency streaming generation while maintaining strong long-term audio-visual consistency. The results further show that OmniMate supports realistic, coherent, and responsive interactive avatar experiences over extended multi-turn conversations.

## 1. 核心问题与研究动机

- **背景**：扩散生成模型已实现高质量人像视频合成，扩散蒸馏技术使音频驱动视频生成接近实时推理；统一音视频生成模型能够联合合成同步的语音、音效与视觉内容，为交互式虚拟形象系统奠定了基础。
- **核心问题**：将统一音视频合成扩展到**开端式实时交互流式生成**存在两大挑战：
  - **生成时长未知**：交互式流式生成中，模型需要在执行过程中不断生成响应，但事先不知道指令内容是否已完整表达，固定时长会截断响应或产生冗余；显式完成检测又引入额外延迟。
  - **长期跨模态身份漂移**：有限时间上下文导致身份线索逐渐淡化；单张参考图难以在未知姿态和视角下保持视觉身份；有限语音上下文难以维持多轮对话中的音色一致。
- **整体含义**：本文提出 OmniMate，一个统一框架，联合实时合成语音、面部运动、身体手势和动作音效，支持多轮自然交互，并在长时间流式生成中保持视觉身份与说话人一致性。

## 2. 方法论

### 2.1 总体架构

- 以 **LTX2.3** 作为骨干网络，采用 DMD 蒸馏实现实时推理。
- 用户语音经 ASR 转写，由 LLM 生成响应内容、动作指令和预测执行时长；执行时长交给 GPC 控制生成节奏；MRCM 注入视觉与音频身份线索。

### 2.2 生成进度控制器（GPC）

核心思想：为每个流式块显式提供当前相对执行进度，使模型能按时完成响应、无缝切换状态。

- **进度编码**：给定 LLM 预测的执行时长，为视频帧分配 1~1000 的进度值：
  
  \[
  p_{v_i} = 1 + \frac{i-1}{T_v - 1} \times 999,\quad i = 1, \dots, T_v
  \]
  
  音频 token 类似：
  
  \[
  p_{a_j} = 1 + \frac{j-1}{T_a - 1} \times 999,\quad j = 1, \dots, T_a
  \]

- 超过预测执行时长的 token 进度设为 0，代表聆听状态。
- 两个模态的进度信号经正弦位置编码和 MLP 后加到对应潜在表示上：\(\tilde{z}_m = z_m + \text{MLP}(\text{PE}(p_m))\)。

- **状态转换数据构造**：利用 DMD 蒸馏的双向教师模型生成包含执行→聆听等转换的 ODE 轨迹，通过段级二值文本交叉注意力掩码控制状态边界：
  \[
  m_i = \begin{cases}1, & i < \tau \\ 0, & \text{otherwise}\end{cases}
  \]
  构造了仅执行、执行→聆听、聆听→执行、聆听→执行→聆听多种状态转换序列。选择 DMD 蒸馏教师而非原始多步教师以避免时间提示泄漏。

- **联合 DMD 训练**：ODE 初始化阶段，学生模型只用执行提示做交叉注意力，状态转换仅由注入的进度控制；DMD 蒸馏阶段，真/伪打分网络使用状态感知文本条件，将教师的状态转换行为迁移给学生。

### 2.3 多参考条件模块（MRCM）

- **视觉身份条件化**：将 N 个参考图像经 VAE 编码后沿时间维度与带噪视频潜在拼接，负 RoPE 防止参考 token 影响生成帧位置。训练时随机采样 4 帧作参考，推理时最多使用 4 张参考图。
- **说话人身份条件化**：免训练策略，用固定热身话语初始化生成过程；有参考音频时，将参考语音潜在在去噪过程中替换原始生成音频潜在，保持音色稳定。

### 2.4 训练与流式推理

- 四阶段训练：①视觉身份条件微调 → ②DMD 蒸馏双向教师构建状态转换轨迹 → ③ODE 初始化联合优化 GPC 和学生模型 → ④自强迫 DMD 蒸馏（每个 chunk 只允许关注参考块、首块和两个相邻块）。
- 推理时用 RollingSink 保持长期视觉稳定性。

## 6. 主要结论与发现

- OmniMate 在速度上显著领先：**27.64 FPS**、TTFF 3.49 秒，优于 OmniForcing（24.83 FPS / 3.51s）和 Hallo-Live（19.22 FPS / 3.63s）。

- 定性结果：基线在长时生成中常见视觉退化、聆听期多余动作/声音、状态切换不准确等问题，OmniMate 能实现平滑状态过渡和高保真生成。

## 7. 优点与亮点

- **问题定位准确**：抓住开放域交互流式的两个本质难点——未知生成时长和跨模态长期身份保持，而非简单复用现有训练方案。
- **GPC 设计精巧**：将进度作为连续条件信号注入潜在表示，配合段级状态转换掩码和 DMD 蒸馏教师构造的训练数据，实现执行/聆听的无缝切换；选择 DMD 蒸馏教师而非多步教师以避免时间提示泄漏，体现了对训练细节的深入思考。
- **训练效率高**：采用 DMD 蒸馏 + 自强迫训练 + ODE 初始化，在有限窗口（参考块+首块+两个相邻块）下实现实时生成，仅需轻量适配即可获得强性能，不同于 StreamChar、WanStream 等依赖大规模训练或大量额外参数的方法。
- **推理加速**：结合 KV 缓存、流水线并行和 RollingSink，兼顾速度与长期稳定性。
