## 摘要
流式视频扩散模型在交互式和动态世界模拟方面取得了显著进展，但传统逐帧生成中的嵌套自回归与去噪循环阻碍了实时部署。最近的滚动窗口方法通过在不同噪声水平下对多个连续帧进行流水线式去噪，提升了吞吐量和长期稳定性。然而，这些方法以相同的精细空间粒度对所有状态进行分词，导致联合去噪窗口中存在显著的噪声相关冗余。我们提出Ms.Forcing，一种高效的流式视频生成范式，它根据每个状态的噪声水平调整空间粒度。其多尺度分块（MSP）为噪声更大的状态分配更粗糙的块，将活动窗口的token数量减少45%，而多尺度自注意力（MSSA）将可见的非汇聚键和值的密度匹配到每个查询尺度，进一步降低注意力成本。由于两种调度均由窗口位置固定，Ms.Forcing保持了静态、硬件友好的计算图。我们进一步引入同质噪声级别DMD（H-DMD），该方法从共享相同源噪声水平的干净预测中组装每个伪视频，从而减少DMD训练序列与推理 rollout 之间的不匹配。多尺度设计有助于抵消通过重叠窗口反向传播带来的额外训练成本。我们通过定量和定性实验表明，Ms.Forcing在单块H200 GPU上达到22.84 FPS，比Rolling Forcing快39.6%，同时在短视频和长视频生成设置中显著提升了VBench分数。

## Abstract
Streaming video diffusion models have made substantial progress toward interactive and dynamic world simulation, but the nested autoregressive and denoising loops of conventional next-frame generation hinder real-time deployment. Recent rolling-window methods pipeline denoising across multiple consecutive frames at different noise levels, improving throughput and long-horizon stability. However, they tokenize every state at the same fine spatial granularity, leaving substantial noise-dependent redundancy in the joint denoising window. We propose Ms.Forcing, an efficient streaming video generation paradigm that adapts spatial granularity to each state's noise level. Its Multi-Scale Patchification (MSP) assigns coarser patches to noisier states, reducing the active-window token count by 45%, while Multi-Scale Self-Attention (MSSA) matches the density of visible non-sink keys and values to each query scale to further reduce attention cost. Because both schedules are fixed by window position, Ms.Forcing retains a static, hardware-friendly computation graph. We further introduce Homogeneous-Noise-Level DMD (H-DMD), which assembles each fake video from clean predictions sharing the same source noise level, thereby reducing the mismatch between DMD training sequences and inference-time rollouts. The multi-scale design helps offset the additional training cost of backpropagating through overlapping windows. We include both quantitative and qualitative experiments to show that Ms.Forcing reaches 22.84 FPS on a single H200 GPU, 39.6% faster than Rolling Forcing, while significantly improving VBench scores in both short video and long video generation setting.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：流式视频生成（streaming video generation）要求实时、低延迟地逐帧输出，同时保持长时程一致性。传统方法采用嵌套的自回归+去噪循环，每帧完全去噪后才生成下一帧，导致误差累积和效率低下。最新滚动窗口方法（如Rolling Forcing）将多帧联合去噪，但所有帧被统一用精细粒度token化，忽略了不同噪声水平下的冗余——高噪声帧只需关注低频结构，低噪声帧才需要细节。
- **整体含义**：现有方法因计算冗余限制了实时部署，尤其是在混合噪声的联合去噪窗口中存在巨大的优化空间。本文提出Ms.Forcing，通过多尺度分块（MSP）和多尺度自注意力（MSSA）根据噪声水平自适应调整空间粒度，同时引入同质噪声级别DMD（H-DMD）消除训练-推理分布不匹配，实现更快、更稳定的流式视频生成。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 利用滚动窗口模型（Rolling Forcing）中噪声水平与窗口位置一一对应的特性，静态地为不同位置的状态分配不同的空间粒度（粗粒度对应高噪声，细粒度对应低噪声），从而在保持计算图静态、硬件友好的前提下大幅减少计算量。
- 同时改进DMD训练策略，使训练序列的噪声分布与推理时一致。

### 关键技术细节
1. **Multi-Scale Patchification (MSP)**  
   - 在联合去噪窗口内，每个帧（或状态）根据其噪声水平被分配一个 patch 大小 \( p_l \)，单调递增（如 \( p, p, 2p, 2p, 2p \)）。  
   - 较粗的 patch 减少 token 数：\( N_{\text{MSP}} = \sum_{l=1}^{T} HW/p_l^2 \)，相对于统一粒度 \( N_{\text{RF}} = T HW/p^2 \) 的 token 保留率 \( \rho_{\text{tok}} = \frac{1}{T} \sum_{l=1}^{T} (p/p_l)^2 \)。在5步RF配置下，保留率为0.55（减少45% token）。  
   - 每一粗粒度层级包含独立的 patch embedding/de-embedding、LoRA适配器和残差分支，但共享底层DiT骨干网络。

2. **Multi-Scale Self-Attention (MSSA)**  
   - 对于不同尺度的 query，其可见的 non-sink 键值（KV）的密度不超过 query 本身的粒度，而 sink KV 保持完整分辨率。  
   - 公式：\( C_{\text{MSSA}}^a = [C_{\text{sink}}; \text{Concat}_{b \in V(a)} \text{Subsample}(C_b, \text{stride} = \max(1, p_a/p_b))] \)。  
   - 在5步RF配置下，MSSA 额外减少了12.9%的点积注意力计算。  
   - 调度固定，无需运行时路由。

3. **Homogeneous-Noise-Level DMD (H-DMD)**  
   - Rolling Forcing 在 DMD 训练时从非重叠窗口拼接“伪视频”，导致相邻帧来自不同噪声级别的预测，造成训练-推理不匹配。  
   - H-DMD 随机采样一个窗口位置 \( j \)，然后从每个连续滚动窗口的相同位置取出预测的干净状态，组装成整个序列。所有帧共享相同的源噪声水平，保证时间边缘分布一致。  
   - 这需要反向传播通过重叠窗口，但 MSP 和 MSSA 使训练变得可行。  
   - 算法流程：初始化滚动窗口，采样j，对每个i进行前向（使用MSP和MSSA），收集\(\pi_j(\hat{W}_0^{(i)})\)，更新KV，更新噪声状态；最后更新fake-score网络和生成器。

2. **高效性**：token减少45%+注意力减少12.9%，端到端速度提升39.6%，且质量不降反升。
3. **训练改进**：H-DMD解决了DMD训练与推理的不匹配，且借助MSP/MSSA抵消了额外反向传播开销。
